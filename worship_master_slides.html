CORE PROPOSITIONS

감정과 체험에 속지 않는 4대 핵심 명제

1. 감정은 죄가 아니다

그러나 감정이 진리의 기준이 되어서는 안 된다. 말씀이 기준이고, 감정은 반응이다.

2. 체험은 열매일 뿐

체험은 예배의 열매가 될 수 있지만, 진리의 근거가 될 수는 없다.

3. 예배의 진짜 목적

감정을 없애는 것이 아니라, 말씀으로 우리의 감정까지 바르게 드리기 위해 예배한다.

4. 위험한 경계선

감정적 음악이 나쁜 것이 아니다. 감정과 체험이 말씀의 권위를 대신할 때 위험하다.

"판단의 기준은 '얼마나 감동적인가'가 아니라
무엇을 믿고 사랑하고 바라보게 하는가 이다."

SONG ANALYSIS 01

우린 물러서지 않으리 ── 결단과 믿음의 전진

🎼 송폼 (Song Form) 및 구조

intro (기타) → A → 간주 → A → B → B → 간주 → A → B → B → 간주 → C → C → C → B

반복적인 고백을 통해 모의고사와 학업의 압박 속에서도 믿음으로 굳게 서서 물러서지 않겠다는 결단을 다지는 구조로 배치하였습니다.

📖 성경적 해석

  • • 코드 진행: A, A/C#, D(add2), E(sus4), F#m7
  • • 묵상 가사: "사랑하는 형제자매 우리 모두 다 마음과 온전한 믿음으로 나아가자..."
  • • 적용: 두려움과 입시 스트레스 속에서 서로를 돌보며 세상 앞에 물러서지 않을 영적 용기를 부여.
SONG ANALYSIS 02

세상 가운데 소망을 ── 조건 없는 은혜의 통로

Intro → A → B → C → A → B → C → Tag → Outro

📖 성경적 해석

  • • 주요 가사: "가진 것 하나도 포기할 수 없는 우릴 위해 주님 모든 것을 내어주셔서 우릴 사랑하시네..."
  • • 적용: 세상의 기준과 경쟁 속에서 지친 영혼들에게 하나님의 무조건적인 사랑과 참된 소망을 재확인.
SONG ANALYSIS 03

함께 지어져 가네 ── 거룩한 공동체의 완성

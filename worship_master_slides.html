SONG ANALYSIS 01

우린 물러서지 않으리 ── 결단과 믿음의 전진

🎼 송폼 (Song Form) 및 구조

intro (기타) → A → 간주 → A → B → B → 간주 → A → B → B → 간주 → C → C → C → B

반복적인 고백을 통해 모의고사와 학업의 압박 속에서도 믿음으로 굳게 서서 물러서지 않겠다는 결단을 다지는 구조로 배치하였습니다.

템포와 다이내믹의 점진적 상승

📖 성경적 해석

  • • 코드 진행: A, A/C#, D(add2), E(sus4), F#m7
  • • 묵상 가사: "사랑하는 형제자매 우리 모두 다 마음과 온전한 믿음으로 나아가자..."
  • • 적용: 두려움과 입시 스트레스 속에서 서로를 돌보며 세상 앞에 물러서지 않을 영적 용기를 부여.
